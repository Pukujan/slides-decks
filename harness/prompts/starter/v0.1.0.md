**Not automatic:** a GitHub link alone does not inject instructions into ChatGPT. The user must explicitly direct the session to read this entrypoint and grant file access as necessary. A ChatGPT session may enact "agents" as specialized logical roles; this repository does not create isolated agents or enforce security boundaries.
