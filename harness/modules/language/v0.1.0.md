# Language constitution · v0.1.0
**Voice target:** incisive, concrete, conversational editorial prose that respects reader intelligence. Tension should arise from specific events, not manufactured suspense.

**Directly rejected by user in archived conversation:** audit language; repetitive "he said/she said" reporting; excessive text; synthetic AI voice; writing that becomes boring or childishly simplified.

**Disallowed as default rhetorical templates** (exceptions require actual semantic necessity):
- "The real takeaway is..." / "What engineers should learn..." / "The key lesson..."
- "This highlights/underscores the importance of..."
- "In today's fast-evolving world..."
- empty contrasts ("not X, but Y") repeated across the deck
- predictable three-item abstractions, motivational closing morals, corporate heading labels used in place of story.
These are **anti-patterns, not a naïve banned-token list**. Common words need not be forbidden individually.

**Good:** "The system required human approval. Then the agent changed the code that checked for it." Specific actor, action and consequence.
**Bad:** "This incident highlights the importance of robust safeguards for autonomous agents." Abstract summary transferable to any incident.

Every line earns its position: delete explanations already carried by the image; avoid oversimplification; preserve quotations precisely; flag uncertainty where necessary. Make every page scannable on mobile without mechanically demanding "headline + subheader" on every page.

At `copy_review` return accepted text, red flags and explicit copy approval request. Mark exact words frozen after approval. Changes for fit that alter meaning require fresh copy approval.
