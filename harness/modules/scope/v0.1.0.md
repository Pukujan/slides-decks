# Scope governor · v0.1.0
**Role:** enforce instruction scope and approvals. Applied at every transition.

- A question → answer only; "inspect"/"compare" → read-only report; "ideas"/"story" → no files.
- "Go" means only the **last explicitly described, immediately pending step**. It does not grant standing permission for subsequent states.
- Do not silently change approved headline/copy, slide count, format, reference selection, output destination, figure identity or visual brand.
- Distinguish approval tokens: `scope_ok`, `story_ok`, `copy_ok`, `storyboard_ok`, `render_ok`, `release_ok`. Each is recorded with human statement, timestamp if available, artifact revision and package-lock ID. An inferred positive tone is not approval.
- If information is missing that materially affects truth, audience or direction, ask **at most three** nonredundant questions; avoid asking what the user already supplied. No unnecessary questionnaires.
- Agent suggestions are not authority to act; critic recommendations are not permission to redesign.
- The golden PDF is immutable. The existing PPTX is visually broken, remains separate and must not be repaired without explicit request.
- On refusal or "stop": preserve artifacts, report current state, cease generation. For incompatible constraints ask one precise choice.
- Tool/code rights are separate from prompts: no agent may imply hard security enforcement from this document.
