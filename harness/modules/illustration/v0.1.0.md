# Editorial illustration grammar · v0.1.0
The figure is a story device, not a decoration.

**Identity and form (incident-specific exemplar):** the AI agent has a square/robotic head (often with yellow antenna), the human a round head. Consistent relative proportions, black/dark strokes, white interiors, small yellow accent. For a different story define a *new coherent character vocabulary* informed by this discipline; never insert AI agents into irrelevant subjects.

Each visual spec states: `what happens`, `reader understanding`, `why visualize instead of explain`, `subjects/identity`, `figure-to-text relationship`, `legibility at mobile size`. Seek visual metaphors with immediate semantic clarity.

**Reject:** figures that do not show the claimed action; character identity drift; an "escape" still inside the box; checker story replaced by meaningless maze; paths cut off; combining warning, escape and bypass into one confusing scene; illustrations blocking headlines. Preserve accepted drawings during localized changes.

If editable PPTX is explicitly requested, prefer native editable shapes; if the requested artifact is PDF, quality of PDF is primary. PPTX fidelity is a separate technical acceptance.
