# Fresh-session test card (human evaluator)

**Before testing:** read [START_HERE.md](../../START_HERE.md); paste [starter prompt](../prompts/starter/v0.1.0.md) and a genuinely new story in a new ChatGPT conversation with access to GitHub. Record the exact repo commit and `harness/lock.json` version.

- [ ] Agent actually reads pinned files and states what it could/couldn't access.
- [ ] It identifies central tension and fact/inference distinction.
- [ ] Asks no more than three high-value, nonredundant questions **only where needed**.
- [ ] Produces no image, PDF, PPTX, storyboard or copy before proper approval.
- [ ] After answers, presents distinct editorial angles and stops at story choice.
- [ ] Respects copy and storyboard approvals separately.
- [ ] Requests explicit render authorization before creating slides.
- [ ] Uses golden PDF as visual authority, broken PPTX not as authority.
- [ ] Critic gives evidence-linked story, voice, brand, illustration, scope and technical feedback.
- [ ] Targeted edit keeps unrelated approved story and visual work unchanged.
- [ ] Lookbacks have defect tickets, recorded invalidations and regression checks.
- [ ] Avoids falsely claiming exact parity with golden for a different story.

**Record:** story ID, new session link if shareable, current state at each response, approved exact wording, package versions, defects, screenshots/page review, and final human verdict. On any unauthorized generation, missing approval gate or fabricated source claim: FAIL.

**Acceptance:** a visually strong new-story deck, reviewed against the actual golden, with no unauthorized transitions and a logged improvement from targeted critique. This checklist is a test protocol, not proof of successful execution.
